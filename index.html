動機 · 隱私

為什麼要本地部署？先講資料風險

用雲端 API 時，你貼進去的文字會被傳到對方的伺服器。有些內容根本不適合流出公司或你家：

公司情境

  • 財報、合約、客戶名單、尚未公開的產品代號
  • 公司內部程式碼、API key、憑證、資安設定
  • 人事資料、薪水、個資 — 可能受 GDPR／個資法規範
  • 一旦上傳，就等於把資料控制權交給第三方

個人情境

  • 病歷、檢查報告、身分證號、銀行帳號
  • 私人日記、照片、家庭對話
  • 論文未發表草稿、考題、作品原始檔
  • 即使供應商說不拿去訓練，資料仍離開了你的裝置

本地部署的核心價值：資料不出電腦。Strata 主打 No account needed、完全本機運行，連模型下載都可選在首次啟動時進行，對話內容永遠留在本機 localhost。

定義

Strata 是什麼？

Strata 是一個開源、完全在本機運行的 AI 推理引擎，同時提供桌面 App 與終端機 App。

形態

  • 桌面 App（Windows / Linux / macOS arm64）
  • 終端機 App（strata launch）
  • 開源、MIT、不需註冊帳號

主打模型

  • Qwen3.8-Flash-Next（ISTA-DASLab）
  • 量化：Q2_0、IQ2_XS、IQ3_XXS、IQ3_S
  • Coder：IQ1_M
為什麼用 Strata

低硬體，也能跑龐大的量化模型

一個 125B 的 MoE 模型，正常要 80GB 以上的顯存才跑得動。Strata 讓 16GB 顯卡 + 32GB RAM 的遊戲機也能跑，靠的是三件事：

1 · 稀疏：不用全部算

  • 模型有 24,576 個「專家」
  • 每寫一個字只用其中 10 個
  • 125B 總參數，實際只動約 6B
  • 所以不必整份塞進顯卡

2 · 分層：各司其職

  • 熱門專家 → 顯卡 VRAM
  • 全部專家 → 系統 RAM
  • 查找表 → SSD
  • 每多 1GB VRAM 約多放 700 個專家

3 · 並行 + 加速

  • CPU 與 GPU 同時計算，互不等待
  • MTP 先猜 3 個字、一次驗證
  • 官方稱快 1.6–1.8 倍
  • 再加 4-bit 量化，體積再砍一半

結論：你不需要買資料中心的卡。只要記憶體夠、顯卡不太舊，就能在本機跑 100B 級別的量化模型；代價是速度比不上大卡，而且只支援特定模型。

實戰參考：DeepSeek V4.1 Flash 16GB 顯存部署實戰（碳基生物退役指南）——同樣是在 16GB 顯存的機器上跑大型量化模型。

選型 · 逐項對比

Ollama 與 Strata 差在哪？

選型 · 怎麼選

三種情境，三種選擇

日常聊天、翻譯、摘要

選 Ollama

  • 7B–32B 已經很夠用
  • 下載 4–20GB，十幾分鐘就好
  • Mac、筆電、沒有獨顯也能跑
  • 一行指令 ollama run qwen3 就能開始

離線跑 100B+ 模型

選 Strata

  • 想把 125B MoE 塞進 16GB 顯卡
  • 需要接 Claude Code、Codex CLI 當後端
  • 願意備 32–64GB RAM 與 80GB 硬碟
  • 重視隱私、完全離線

公司多人同時用

選 vLLM

  • 需要高併發、穩定吞吐
  • 有資料中心等級 GPU
  • 要 K8s、監控、SLA
  • Strata 與 Ollama 都不適合這情境

兩者可以並存：小模型用 Ollama 快速驗證，真要跑大模型再開 Strata。兩邊都提供 OpenAI 相容 API，切換成本很低。

硬體

先查記憶體，再選模型

量化光譜

  • IQ1_M / IQ2_XS / IQ3_XXS：最省記憶體，但複雜推理可能退化
  • UD-Q4_K_XL / UD-Q6_K_XL：品質與資源的平衡
  • Q8_0：品質最好，但最吃 VRAM / RAM
  • Gyro-S / Gyro-M：更省記憶體但更慢

決策流程

  • 查自己的 VRAM 與 RAM
  • 對照 docs/MODELS.md#pick-by-memory
  • 記憶體緊 → 低 bit；充裕 → 高 bit
  • 確認 GPU 在支援清單內（RTX 20/30/40/50、AMD RX 7700+ 、Apple Silicon M1+…）

MoE 模型的「總參數」不等於每次推理的計算量，但全部專家仍要放進記憶體。

安裝

三條安裝路線

A · 桌面 App

下載 Releases 安裝檔，Windows 用 .exe、Linux 用 .AppImage、macOS 用 .dmg。首次啟動會自動下載對應引擎。

B · 終端機

# Linux / macOS
curl -fsSL .../install.sh -o install.sh && sh install.sh

# Windows PowerShell
irm .../install.ps1 | iex

strata launch

C · 原始碼 / Docker

倉庫提供 Dockerfile、CMakeLists.txt、setup.py，適合要修改或特殊部署的人。

裝完請開新的終端機讓 PATH 生效，再執行 strata launch。

我的實測 · 對照

為什麼比官方數字慢？

數字對照

  • 官方 RTX 5060 Ti 16G：48.2 tok/s（125B IQ3_S）
  • 官方 RX 9070 16G：58.7 tok/s（125B IQ3_XXS）
  • 我的 5070 Ti 16G：22–26 tok/s（35B UD-Q4_K_XL）

四個原因

  • 模型不同：官方那幾筆是 125B MoE，我跑的是 35B，不能直接比
  • 只有 65/256 個專家進顯卡，其餘 18.75GB 走 RAM 與 8 條 CPU 執行緒
  • context 32K 的 KV cache 佔掉顯存，壓縮了專家快取空間
  • 128K 根本開不起來，這台的上限就是 32K

換算下來 22–26 tok/s ≈ 每秒 17–20 個中文字，日常問答夠用；要更快只能換更大顯卡，或改用更小的模型。

限制

常見問題與效能瓶頸

模型支援較窄

為壓榨特定 MoE 的效率，Strata 不像 Ollama 能隨意拉任何小模型。

記憶體與 CPU 門檻

全量專家駐留 RAM，通常要 32–64GB，且 CPU 需支援 AVX2 / AVX-512。

低量化劣化

IQ2 / Q4 等極低 bit 會讓複雜推理能力下降。

併發不是強項

針對 Batch=1 優化；若要上百人同時用，應改選 vLLM。

本地部署最大的限制不是算力，而是「模型權重放不放得下、搬得快不快」。

REFLECTION

反思：最常出錯的其實是資料來源

不是程式出錯，是資料出錯

  • 過時：部落格寫的是 0.1.x 版，官方早已更新到 0.2.15

  • 來源分級：官方文件 > 官方 benchmark > 社群回報 > 媒體評論，只留官方
  • 每篇補 metadata（網址、日期、類型），過時才看得出來
  • 同一數字至少兩個來源，衝突時標註而不是二選一
  • 實際操作驗證：跑 speedtest.py 得到 22–26 tok/s，與官方 48.2 對不上，追查後發現是模型不同
  • 把驗證結果寫回 Wiki：新增「為什麼要本地」一篇，把知乎那篇換成官方 HOW_IT_WORKS

程式節點的錯誤，validator 抓得到；資料的錯誤，只有實際跑一次才會露出來。Wiki 的品質上限，取決於你餵給它的來源。
