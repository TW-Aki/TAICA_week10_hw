# 為什麼要本地部署

本地部署（local deployment）指的是把模型下載到自己電腦或公司伺服器執行，對話與資料都不必傳到外部。Strata 主打 No account needed、完全本機運行，正適合這種需求。

## 一、資料風險：哪些內容不適合上雲端

使用雲端 API 時，輸入的文字會被傳送到供應商伺服器。以下內容尤其不適合：

### 公司情境

- 財報、合約、客戶名單、尚未公開的產品代號
- 公司內部程式碼、API key、憑證、資安設定
- 人事資料、薪水、 個人資料，可能受個資法或 GDPR 規範
- 一旦上傳，等於把資料控制權交給第三方

### 個人情境

- 病歷、檢查報告、身分證號、銀行帳號
- 私人日記、照片、家庭對話
- 論文未發表草稿、考題、作品原始檔
- 即使供應商承諾不拿去訓練，資料仍已離開裝置

本地部署的核心價值是**資料不出電腦**。對話內容永遠留在本機 `localhost`，不需要帳號，也不經過第三方。

### 實際試算

若有個服務每天 1 萬次請求，每次約 1,000 輸入 token + 500 輸出 token：

- 每天：1,000 萬輸入 + 500 萬輸出
- 用 GPT-4.1 等級定價試算，每天約 $60，一個月約 $1,800
- 用便宜的 Flash-Lite 等級，成本約降到十分之一，但品質也下降

本地部署則是一次性硬體成本（例如 RTX 5070 Ti 約數百美元），之後每次推論的邊際成本接近電費。對高頻使用或長期專案，本地往往更划算。

## 三、其他好處與代價

好處：

- 離線可用，沒網路也能聊天、寫程式
- 可自己決定模型版本、量化等級，不被供應商改版影響
- 延遲穩定，不依賴網路往返

代價：

- 要自己處理模型下載、量化選擇、記憶體配置
- 硬體有門檻，需要足夠 VRAM 與 RAM
- 維護與更新都要自己來

## 小結

如果處理的是機敏資料、高頻呼叫，或重視隱私與自主權，本地部署值得考慮；若只是偶爾問答、且資料不敏感，雲端 API 仍然方便。兩者並非互斥，Strata 也提供與 OpenAI／Anthropic 相容的 API，可與雲端混用。
